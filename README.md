# DMIT VPS 测评：Pro、EB、T1 三条线路怎么选，配置、真实价格和下单前该确认的细节

搜"DMIT VPS 测评"的人，问题通常不是一个，而是一串：这台机器延迟到底多少、晚高峰会不会掉速、官方说的不超售是不是真的、$12.98 一个月和 $36.9 一年差在哪、以及——现在到底还有没有货。

所以这篇不按"开箱—跑分—总结"的套路写。先把最影响决策的几件事说清楚：线路差在哪、涨价之后性价比怎么变、以及你该在结算页上确认什么。

## 先搞清 DMIT 的产品逻辑：不是按配置分层，是按线路分层

DMIT 2017 年成立，注册地在美国，机房目前主要在洛杉矶、香港、东京三地。它跟多数 VPS 商家的思路不太一样——同样 1 核 2G 的配置，它会给你三种完全不同的网络，价格能差好几倍。这台机器"贵"，贵的从来不是 CPU，是回国的那条路。

三条线路的含义：

- **Premium（Pro）**：电信去程走 CN2 GIA（AS4809），联通去程直连 AS4837，移动去程走香港移动 AS58453，三网回程统一 CN2 GIA。面向中国大陆访问体验最好的一档，也最贵。
- **Eyeball（EB）**：回程以 CMIN2 为主，电信在 AS9929 与 AS58807 之间做负载均衡，联通走 AS9929，移动走 CMIN2。它是"尽力而为"的中国优化，带宽和流量给得比 Pro 更宽松。
- **Tier 1（T1）**：纯国际 BGP，不含中国大陆专项优化。它的价值在带宽大、流量多、价格低，适合纯海外业务、备份、CI/CD、中转落地。

判断方式很简单：你的访客或你自己主要在大陆，看 Pro 和 EB；你只是要一个便宜的海外节点，看 T1。选错这层，后面配置怎么挑都是白挑。

## 平台换代这件事，直接改变了价格预期

2026 年 4 月 13 日，DMIT 下架了洛杉矶 AN4 平台（AMD EPYC 9004）的机器，包括当时 $9.9/月 那批低价款，只保留新平台 AN5（AMD EPYC 9005）。重新上架后入门档涨了：TINY 从原来的 $9.99/月 变成 $37.99/季起，年付从 $88 提到 $119.99，两款最低配也取消了月付、最低按季付下单。

后来洛杉矶又补了 AS3 平台（AMD EPYC 7003），价格比 AN5 低一档，Pro.TINY 回到 $10.9/月，T1.WEE 年付 $36.9。所以现在你在官网看到的同一档套餐，可能挂在 AS3 或 AN5 两个平台上，参数接近、价格不同、库存随时变。

这里有个实用结论：**AN5 的 CPU 性能对大多数人其实是过剩的。** 一个 1 核 2G 的机器跑单核 GB6 能到 2650+（第三方实测数据），这个水平拿来建站都够。如果你只是轻量建站、科学上网、跑中转，别为了平台代际硬上 AN5 加钱，AS3 更划算。

## 第三方实测数据能确认什么

把公开测评里的数字挑几个关键的摆出来，比形容词有用：

- 洛杉矶 EB 系列（AN5、EPYC 9655）第三方测试：磁盘 I/O 约 1.1GB/s，10Gbps 共享端口，国内平均延迟约 160ms 上下。
- 洛杉矶 T1.TINY 测试：AMD EPYC 7443P，硬盘平均读写约 948MB/s，但全国三网平均延迟约 208ms——因为无中国优化，联通回程甚至绕欧洲。这就是 T1 和 Pro/EB 的真实差距，不是营销话术。
- EB 系列的电信回程在测评中显示走 AS906 → AS10099 → AS9929，联通走 AS9929，移动走 CMIN2。

关于流媒体解锁，得说句实话：不同 IP 段结果差别很大，同一系列有人测出 Netflix、Disney+ 解锁，也有人测出只有 TikTok、YouTube 能开。**别把流媒体解锁当买点**，IP 段的运气成分太重。

超量限速是 DMIT 比较实在的一个设计：Pro 和 EB 用完套餐流量后不停机，降到 4–10Mbps 继续跑；T1 更宽松，降到 100–500Mbps。对偶尔跑超的个人用户来说，这比直接断网舒服得多。

## 香港和东京：什么时候值得加钱

香港机房的核心价值只有两个字：距离。它到内地的物理延迟比美西低一大截，HKG.Pro 走高防 CN2 GIA，是 DMIT 里体验最接近国内服务器的一档。代价也直白：HKG.Pro.TINY（1核1G/20G/500G/1Gbps）$39.9/月，差不多是洛杉矶同档的好几倍。对延迟有硬要求、面向大陆用户做实时交互的应用，这钱才花得值。

东京 TYO.Pro.TINY（1核1G/20G/0.5TB）在公开整理里是 $21.90/月，定位在两者之间。另外要注意：香港 EBv2 产品线已于 2026 年 8 月 10 日停产停服，原用户按剩余时间退款到账户或原支付渠道。买香港的话，优先确认当前在售的是 Pro 还是 T1，别按旧文章的产品线名字下单。

## 优惠码现状：能用的和别指望的

目前多个渠道仍在提到的一个可用码是 `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF`，适用范围是洛杉矶 Eyeball 系列 TINY 及以上、非月付周期，8 折且是循环折扣（也就是续费也打折）。这类循环折扣的实际价值比一次性优惠高——它的作用是把价格结构改掉了，而不是省你第一个月。

至于圣诞期间那批 `2025-XMAS-...` 开头的 LAX 折扣码（Pro/EB 年付 STARTER 及以上 15% 折扣 + 10% 返现、T1 10% + 5% 返现），属于节日活动码，节日过后能否继续用在结算页验证一下就知道。别看着标题里写"最新"就直接抄，优惠码是最容易过期的一类信息。

使用方式都一样：选好套餐和计费周期 → 结算页填入码 → 点 Validate Code 验证折扣是否生效。不同码对应不同产品线和周期，串了就不生效。

## 下单前该确认的几件事

**IP 更换。** DMIT 在 2026 年初更新了换 IP 策略：洛杉矶 Pro 和 EB 支持自助更换，付费更换 $5/次 无需审核，免费更换需要审核；全区域 T1 只支持付费更换，且要过审核。流程一般是提交后 24 小时内审完，通过后 48 小时内确认，确认完约 10 分钟切好。早期"每 15 天免费换一次"的说法已经不适用于当前政策，别按旧信息做判断。

**付款和沟通。** 支持支付宝、微信支付、PayPal 和信用卡，工单可以用中文，这在美系商家里算少见。对不想折腾国际支付的人，这一点实际比参数重要。

**系统。** 4GB 内存以上的套餐才支持 Windows，低配只能跑 Linux 发行版，装之前先确认。

**退款和升级。** 这里必须诚实：我没有在可核验的官方条款里确认到当前的完整退款政策，所以不写具体天数。但有一条逻辑是清楚的——DMIT 的库存策略是"卖完不补"，热门特价档常年处于售罄状态，看到有货再纠结"再等等看有没有更便宜的",通常的结局是等没了。

**不超售。** 官方明确承诺不超售，这也是 DMIT 在圈内口碑的主要来源。它不是官方可查指标，但可以从价格上反推：同样的配置它比多数商家贵，贵的那部分换的就是别人抢不走的带宽。
